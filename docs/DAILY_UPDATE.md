# 财经日报日更说明（供 Cursor 自动化执行）

## 目标

每天生成一份可核验的财经日报 JSON，写入本仓库，供网页直接展示。

## 硬性规则（不得违反）

1. **禁止编造新闻**：每条新闻必须有可点击的公开来源 URL；标题、要点须与来源一致。
2. **禁止编造数据**：利率、GDP、CPI、股价等数字必须来自引用来源；不确定则写“来源未提供具体数值”。
3. **区分事实与推断**：`summary` 只写报道事实；`impacts` 写基于公开信息的合理推断，并使用“可能/或将/市场关注”等措辞，不写成确定预测。
4. **不构成投资建议**：不得出现“买入/卖出/加仓”等建议性表述。
5. **数量**：选取当日 3–6 条重要财经新闻（宏观政策、央行、就业通胀、重要财报/监管、大宗商品/汇率中具有广泛影响者）。
6. **语言**：简体中文。

## 推荐可靠来源（优先）

- 新华社、中国政府网、央行官网、国家统计局
- 路透社、彭博、华尔街日报、金融时报、BBC Business
- 证监会/银保监会等监管机构官方通告

优先一手或权威媒体；自媒体、无署名传言不采用。

## 输出文件

1. 写入 `data/daily/YYYY-MM-DD.json`（日期为 Asia/Shanghai 当日）。
2. 更新 `data/index.json`：
   - `latest` = 当日日期
   - `editions` = 将当日日期插入数组开头（去重，保留最近 30 天）

## JSON Schema

```json
{
  "date": "YYYY-MM-DD",
  "timezone": "Asia/Shanghai",
  "title": "财经日报",
  "generatedAt": "ISO-8601 带时区",
  "disclaimer": "本页解读基于公开报道整理，不构成投资建议。知识点为一般性经济学说明；影响分析属基于公开信息的合理推断，可能与实际走势不符。",
  "items": [
    {
      "id": "YYYY-MM-DD-01",
      "headline": "新闻标题（与来源一致或忠实概括）",
      "summary": "2–4 句事实摘要，不掺入主观预测",
      "concepts": [
        {
          "term": "知识点名称",
          "explanation": "用通俗语言解释背后的金融/经济学概念"
        }
      ],
      "impacts": {
        "domesticEconomy": "对国内经济可能的影响（推断）",
        "globalEconomy": "对国际经济可能的影响（推断）",
        "markets": "对股市/债市/汇率等可能的传导（推断，非投资建议）"
      },
      "sources": [
        {
          "publisher": "媒体或机构名",
          "title": "原文标题",
          "url": "https://...",
          "publishedAt": "YYYY-MM-DD 或更精确时间"
        }
      ]
    }
  ]
}
```

## 执行步骤

1. 用网络检索获取当日权威财经新闻（至少覆盖中美欧或中国宏观之一）。
2. 对每条新闻打开/核对来源页面，确认标题与要点。
3. 为每条写 1–2 个相关知识点（概念解释，非新闻复述）。
4. 撰写影响分析，明确标注为可能影响。
5. 写入上述两个 JSON 文件；保证 UTF-8、合法 JSON。
6. 提交并推送到默认分支（若具备仓库写权限）：commit message 形如 `daily: YYYY-MM-DD 财经日报`。

## 失败处理

若当日无法获得足够可核验来源（少于 3 条），仍生成文件，但 `items` 仅包含已核验条目，并在文件顶层增加：

```json
"notes": "今日可核验来源不足，仅收录 N 条。"
```

绝不填充虚构新闻凑数。
